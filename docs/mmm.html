Read before acting

  • Still observational data. The causal reading is only as good as the controls — miss a confounder (a competitor's price cut) and the intervals will be confidently wrong.
  • Priors can dominate. Check the prior-vs-posterior panel; a posterior that copies its prior isn't evidence.
  • Correlated channels are hard to separate. If two channels always flight together, only geo-level differences or deliberate tests can split them.
  • Best practice: feed periodic lift-test results back in as ROI priors. The model and the experiments keep each other honest.
